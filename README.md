# BIG RED INTERNET BUTTON
Dictator with nuclear war heads simulator

Plan:
User interface is a big red button, powered by the [ESP32-C3 rust board](https://github.com/esp-rs/esp-rust-board/tree/master). When pushed it sends world destroy message to backend. Backend should
be written with Rust and Axum to survive from nuclear fallout. Backend should have some admin page to watch world destroy and log all the previous blowns.
